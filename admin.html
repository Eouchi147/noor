First-time setup (one time, 2 minutes):
In Vercel → your project → Settings → Environment Variables, add:
1. ADMIN_PASSWORD, your chosen password (long!)
2. ADMIN_SECRET, any random 40+ characters
3. STRIPE_SECRET_KEY, from your Stripe dashboard (starts sk_live_)
4. OPENROUTER_API_KEY, from openrouter.ai (starts sk-or-), lights The Lantern AI
Then redeploy (Deployments → ⋯ → Redeploy) and reload this page.

Turn on the lamp counter (5 minutes, one time). Two roads, either works:

Road A · you already have a Redis account

  1. In your Redis provider (Redis Cloud, Upstash, Railway, anywhere), open the database and copy its connection URL. It looks like redis://default:PASSWORD@host:port, or rediss:// if it uses TLS
  2. Vercel → your noor project → Settings → Environment Variables → add REDIS_URL = that whole URL → Save
  3. Deployments → ⋯ on the latest → Redeploy

Road B · you want Vercel to make one

  1. Vercel → your noor project → Storage tab → Create Database. Vercel no longer sells its own KV, so this shows marketplace providers
  2. Choose Upstash (Redis), name it noor-lamps, create it on the free plan, then Connect Project and pick noor. The keys add themselves
  3. Deployments → ⋯ on the latest → Redeploy

Then reload this console. Counting starts from that moment, cookie-free; no reader is ever identified. The house accepts REDIS_URL, or KV_REST_API_URL with KV_REST_API_TOKEN, or the UPSTASH_REDIS_REST_* pair, whichever your provider gives.

The Lantern reads the numbers

It sees exactly what is above, and answers in the house voice: what is working and should be doubled, what is weak, and the one thing to do tomorrow. It will say plainly when the numbers are still too small to mean anything.

Counting is first-party and cookieless: the day, the country the host attaches, the room, and a coarse source name such as reddit or google. Never an IP, never an ID, never a full URL. A source is counted once per reader per day.

The four laws every message obeys

UnseenNo name, no face, no personal story. The project speaks: hello@noorcodex.com, signed The NOOR Codex team.
Useful firstEvery message hands over something real before it asks anything, and is worth reading by someone who never gives a penny.
Never pushyNo urgency, no guilt, no hype, no emoji. One light ask, placed late, with a graceful way to say no.
PureOnly what truly exists on the site today. No invented numbers, endorsements or claims. Nothing that would embarrass the house.

The Lantern is bound to these four before it writes a single word. It cannot sign your name, cannot invent a testimonial, and cannot manufacture a deadline.

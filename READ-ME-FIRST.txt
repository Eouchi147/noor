WHAT BROKE
────────────────────────────────────────────────────────────────────

From your own Vercel runtime log:

    /var/task/api/card.js:141
        const req = (0, _module.createRequire)(import.meta.url);
    SyntaxError: Cannot use 'import.meta' outside a module

Your package.json has no "type": "module". Vercel therefore compiles
every file under api/ from ES modules to CommonJS at build time. Its
own build log says so:

    Warning: Node.js functions are compiled from ESM to CommonJS.

Nearly everything survives that rewrite. `import.meta.url` cannot:
there is no import.meta in CommonJS. I used it in the new card route
to find the picture library, and it killed the whole file at load, so
even the SVG path 500'd.

This is mine. Node printed a warning about it on every local test run
and I filtered it out as noise.

version of that guard used a regular expression to ignore comments and

confirming it fails.

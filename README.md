The full Codex is ready in the workspace:

- 6 manuscript illustrations (no faces): Arsh, Ark, Kaaba, Hira, Sirat + Hamza seal

- Design system: parchment / ink / gold

## Deploy (recommended)

1. Download the complete zip from the artifacts (`noor-codex-complete.zip` ~2.7 MB)
2. Unzip
3. Go to [vercel.com/new](https://vercel.com/new)
4. Drag the entire `noor` folder onto the deploy area
5. Or connect this GitHub repo and set the root to the project folder

Alternatively with CLI:
```bash
npm i -g vercel
cd noor
vercel --prod
```
